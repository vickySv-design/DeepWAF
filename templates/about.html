Project Overview

DeepWAF integrates traditional signature-based filtering with a Character-Level 1D Convolutional Neural Network to automatically detect SQL Injection, Cross-Site Scripting, and obfuscated web attacks in real time. The system intercepts incoming HTTP requests through a Flask-based reverse proxy, performs fast regex-based signature checks to block known attacks, and forwards suspicious or obfuscated payloads to the CNN model for behavioral analysis.

System Architecture

Detection Pipeline: HTTP requests are first validated against signature patterns. Clean requests are allowed immediately, known attacks are blocked, and suspicious requests undergo CNN analysis.

Character-Level Processing: Each request is converted into a fixed-length character sequence using ASCII encoding and padding, then passed through an embedding layer followed by stacked Conv1D and pooling layers that automatically learn malicious patterns without manual feature engineering.

Methodology

Preprocessing: HTTP requests are normalized and converted to character sequences (500 characters max).

Character-Level Encoding: Each character is mapped to its ASCII value, creating a numerical sequence suitable for CNN input.

CNN-Based Feature Extraction: The model uses embedding layers (256→128 dimensions), two Conv1D layers (128 and 64 filters), max pooling, and dense layers for classification.

Training: The model is trained using the CSIC 2010 HTTP dataset with binary cross-entropy loss and Adam optimizer over 20 epochs.

CNN Model Design

Architecture: Character-Level 1D Convolutional Neural Network

Framework: PyTorch

Total Parameters: 160,065

Layers: Embedding (128-dim) → Conv1D (128 filters) → MaxPool → Conv1D (64 filters) → GlobalMaxPool → Dense (64 units) → Dropout (0.5) → Output (Sigmoid)

Performance Evaluation

98.7% Accuracy
98.5% Precision
99.1% Recall
98.8% F1-Score

The model achieves strong performance across all metrics, demonstrating effective detection of both known and obfuscated web attacks while maintaining low false positive rates.

Key Objectives

• Develop a hybrid detection system combining signature-based and deep learning approaches

• Implement character-level CNN for automatic pattern learning without manual feature engineering

• Achieve real-time detection with minimal latency (~10ms for CNN analysis)

• Provide comprehensive logging and analytics for security monitoring

• Create a deployable web application for practical demonstration

Dataset

CSIC 2010 HTTP Dataset: Industry-standard dataset containing normal and anomalous HTTP requests for web attack detection research.

Training Data: 1,860 samples (960 malicious, 900 benign) including SQL injection, XSS, and obfuscated attack patterns.

Conclusion

DeepWAF demonstrates the effectiveness of Character-Level CNNs for web application security. By automatically learning attack patterns from raw character sequences, the system achieves high detection accuracy while maintaining low latency. The hybrid approach combining signature-based and CNN-based detection provides robust protection against both known and novel attacks, making it suitable for real-world deployment.
